Works entirely in your browser against the public GitHub API — no sign-in, no server. Unauthenticated GitHub requests are rate-limited (about 60/hour), so very large repos may need a retry later. Private repos return “not found” and are out of scope. Binary pre-filter borrowed from the gitparts engine; fetch-time content sniffing (NUL byte + printable ratio) is the real gate.
